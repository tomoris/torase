# 目標

- 計画言語を設計する
- 設計する計画言語は母語に関わらず、学習・運用しやすいことを目指す
  - 手話や点字もスコープに含める
- 計画言語の処理系をソフトウェアとして実現する
  - 字句解析
  - 品詞推定
  - 構文解析
  - 述語項解析・格解析
  - 型検査
  - 論理推論
- ソフトウェアエンジニアリングの手法を用いて、計画言語の開発を管理する
  - 正常系のだけでなく、過剰生成や過小生成の異常系もテストできる
  - セマンティックバージョニング
- 計画言語の便利機能をソフトウェアとして実現する
  - 言語サーバー
  - webエディタ

## 目標としないこと

- 計画言語の設計では語用論をスコープ外とする
- クレオール化のような第二言語として学ぶものに不利な変化を認めない

# 計画言語の設計方針

- 学習者の理解難易度、受信者のコミュニケーション負荷、送信者のコミュニケーション負荷が(この優先順位で)それぞれ低くなるように
  - 小さな問題に分割する
- 非決定的より決定的に
  - 処理の上流側では一意に定まるように
    - 例えば、語の一部における表記法は音素列と記号(音素列を特別な記号に一対一変換したもの)のどちらも許し、表記するタイミングで自由に選択できるが、同一文字列が複数の品詞になりうることは許さない
