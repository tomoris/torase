## 内容語

名詞、形容詞・副詞などの修飾詞は述語から派生させる。

### 述語

二項述語と単項述語に分かれているが、単項述語は統語論において二番目の項にεが入ってる二項述語とみなす。
述語はhとs以外の子音から始まり、二音節以上持つ。

#### 名詞を表す述語

f(x1, x2)という二項述語で表現され、x1はx2をxxと定義するという命題を表す。
WordNetの階層構造に従い、第一音節が決まり、第一音節の子音は有声音である。

##### 空間・時間を表す名詞述語(z系)

空間・時間に関わる概念はWordNetでは`abstraction.n.06`(関係・尺度)に存在するが、`heni`/`hene`/`heno`(空間格)・`hegi`/`hege`/`hego`(時間格)の型検査で他の関係・尺度概念(親族関係、因果関係、重さ・体積の尺度など)と混同しないよう、専用の音節グループとして独立させている。

- `za[CV]+` (空間関係。例:「中」「上」「近く」)
  - abstraction.n.06 -> relation.n.01 -> spatial_relation.n.01
- `zi[CV]+` (時間関係。例:「前」「後」「間」)
  - abstraction.n.06 -> relation.n.01 -> temporal_relation.n.01
- `zu[CV]+` (時間の尺度。例:「日」「分」「年」)
  - abstraction.n.06 -> measure.n.02 -> time_period.n.01
- `ze[CV]+` (空間の尺度。例:「メートル」)
  - abstraction.n.06 -> measure.n.02 -> linear_measure.n.01

`za`/`zi`/`zu`/`ze`はそれぞれ`SpatialRelation`/`TemporalRelation`/`Duration`/`Distance`型として扱われる。

#### 動詞を表す述語

f(x1)もしくはf(x1, x2)という形式で表され、x1は???をする(自動詞)もしくはx1はx2を対象にとりxxをする(他動詞)という命題を表す。
x1, x2に取れる項は、名詞を表す述語で用いた第一音節の分類に基づく。

- `pa[CV]+` (生物x1が生物x2をxxxする)
  - x1: `bV`, x2: `bV`
- `pe[CV]+` (生物x1が生物以外の物理的実体x2をxxxする)
  - x1: `bV`, x2: `dV|nV`
- `pi[CV]+`, (生物x1がxxxする)
  - x1: `bV`
- `po[CV]+` (生物以外の物理的実体x1が生物以外の物理的実体x2をxxxする)
  - x1: `dV|nV`, x2: `dV|nV`
- `pu[CV]+`, (生物以外の物理的実体x1がxxxする)
  - x1: `dV|nV`
- `ka[CV]+` (生物x1が抽象概念x2をxxxする)
  - x1: `bV`, x2: `gV|mV|rV|zV`
- `ki[CV]+` (生物以外の物理的実体x1が抽象概念x2をxxxする)
  - x1: `dV|nV`, x2: `gV|mV|rV|zV`
- `ku[CV]+` (抽象概念x1が抽象概念x2をxxxする)
  - x1: `gV|mV|rV|zV`, x2: `gV|mV|rV|zV`

### 項

人称代名詞

- `mi` (私)
- `ma` (私とあなたたち)
- `mu` (あなたを含まない私たち)
- `ba` (あなた)
- `bu` (あなたたち)
- `ga` (誰か、単数か複数か指定しない)
- `gi` (彼/彼女)
- `gu` (彼ら)

指示代名詞

- `me` (これ)
- `be` (それ)
- `ge` (あれ)

指示代名詞は指示物の種類を限定しないため、生物・人工物・その他物理的実体・抽象概念に加えて、空間(`heni`/`hene`/`heno`格の「ここ/そこ/あそこ」)や時間(`hegi`/`hege`/`hego`格の「いま/そのとき/あのとき」)も指すことができる。

#### 定義用のスキーマ変数

- `ha` (x1のスキーマ変数)
- `hu` (x2のスキーマ変数)

`ha`/`hu`は指示代名詞と同じく指示物の種類を限定しない。ただし通常の代名詞(定数として、特定の指示対象を表す)とは異なり、`ha`/`hu`は述語論理上の**変数**として扱われる。単独では意味を持たず、文頭マーカー`hi`(後述)の直後で量化子(`ta`/`to`)とともに明示的に宣言されて初めて量化される。宣言されずに`ha`/`hu`を使うと、束縛されない変数が残るため型検査でエラーになる(「定義専用」であることが規約ではなく検証によって強制される)。`hi`の量化子宣言に`ha`/`hu`以外の項(`mi`等)を使うことも、`ta`/`to`以外の量化詞(`te`/`ti`)を使うこともエラーになる。

用途は主に、`dictionary.json`の`definition_conlang`(語義を計画言語自身で書くフィールド。[辞書ファイルの形式](../dictionary_format.md)参照)で、新語を既知語で言い換える定義文を書くこと。例えば新語`kagurita`を既知語`kaho`(x1はx2に肯定する)で定義する場合:

```
hi ta ha ta hu kagurita sa ha si hu hehezu kaho sa ha si hu
```

これは論理式として`∀ha. ∀hu. (kagurita(ha,hu) ↔ kaho(ha,hu))`になる(`hehezu`については「接続詞」の節を参照)。量化子宣言は`hi`の直後に`(ta|to) 変数`の組を必要なだけ並べる形で、単項述語の定義であれば`hi ta ha [本文]`のように`ha`だけを宣言すればよい。

## 機能語

### 疑問文マーカー

- `ku`
- `?` (読み、発音は`ku`)

### 全称量化マーカー

- `hi`

文の先頭に置く(`ku`と同じ文法上の位置。開始マーカーのみで閉じマーカーは無い)。直後に量化子(`ta`=∀ または `to`=∃)と変数(`ha`/`hu`。定義用のスキーマ変数。「項」の節を参照)の組を必要な数だけ並べてから、平叙文が続く。

```
hi (ta|to) ha (ta|to) hu [平叙文]
```

例えば`hi ta ha to hu [本文]`なら`∀ha. ∃hu. [本文の論理式]`になる。宣言は`ha`のみ・`hu`のみ・両方のいずれでもよく、宣言した変数だけが対応する量化子で閉じられる。`ha`/`hu`を使わない通常の文には付けない。

`ta`/`to`は元々「量化詞」節で述べたNP量化詞(`ta`=すべての、`to`=少なくとも1つは存在する)だが、全称量化=対象すべてに成り立つ(≈∀)・存在量化=対象の少なくとも1つに成り立つ(≈∃)という対応が個体の量化そのものであるため、`hi`の量化子宣言でも同じ語を`ta`=∀・`to`=∃として再利用する。`te`(多くの)・`ti`(半分の)は古典論理の∀/∃に還元できない一般量化詞であり、`hi`の宣言・後述の様相の量化力のどちらにも使えない(使うと型検査でエラーになる)。

### 様相論理

#### 量化力

「量化詞」節の`ta`/`to`を、可能世界に対する量化として再利用する。必然性=すべての可能世界で成り立つ(≈∀=`ta`)・可能性=ある可能世界で成り立つ(≈∃=`to`)。

- `ta` (必然)
- `to` (可能)

##### モーダルベース

- `hapa` (認識)
  - 量化対象：話し手が知っている事実と矛盾しない世界 w_{epi}
  - hapa ta e (確実にe)
  - hapa to e (eかもしれない)
- `hapi` (義務)
  - 量化対象：法律・規則・道徳を守っている世界 w_{deon}
  - hapi ta e (eしなければならない)
  - hapi to e (eしてもよい)
- `hapu` 能力・状況
  - 量化対象：現実の能力・環境条件を保持した世界 w_{cir}
  - hapu ta e (eを必ずできる)
  - hapu to e (eすることができる)

### 述語の反意化

- `no` — 述語の直前(`ne`と同じ構文位置)に置く単項の派生形態素。論理演算子ではない。

`ne`は命題・事象レベルの否定であり、「Pという事象が存在しない」(`¬∃e.(P(e) ∧ …)`)という矛盾対当(contradictory: PとPでないの二値、隙間が無い)を表す。対して`no`は述語そのものを、元の述語とは独立した新しい原子述語(`no P`は`P`とは無関係な`P`の反意形)に反意化する派生であり、`no P`と`P`の間に論理的な関係(例えば「両方は同時に成り立たない」)は型検査でも意味論(`to_fol`)でも一切保証しない。これにより「良くも悪くもない」のような、`P`にも`no P`にも当てはまらない反対対当(contrary)の隙間を自然に表現できる。

`no`は`ne`と同じ「述語の直前に立つ単項演算子」という構文的な地位を共有するため、`ne no P`/`no ne P`/`no no P`のように直接スタックすることはできない(`ne ne P`が禁止されているのと同じ規則)。`hoba`/`hobi`/`hobu`配下にネストした場合は、両方の述語にそれぞれ反意化がかかる。

`no`は`ne`と同様に文法上の派生パーティクルであり、辞書(`dictionary.json`)に見出し語として登録する対象ではない。既存語の対義語が欲しい場合、新しい借用語を追加するのではなく使用時に`no <既存語>`とその場で合成する(詳細は[辞書フォーマット](../dictionary_format.md)を参照)。

### 量化詞

- `ta` (すべての)
- `te` (多くの)
- `ti` (半分の)
- `to` (少なくとも1つは存在する)

`ta`(∀に対応)・`to`(∃に対応)は、「全称量化マーカー」節の`hi`宣言、および「様相論理」節の量化力(必然`ta`・可能`to`)としても再利用される。`te`/`ti`はNP量化詞としての用途に限られる。

### 数詞

量化詞`ta`/`te`/`ti`/`to`は母音`a/e/i/o`のみを使い、`tu`だけが未使用のまま残っている。数詞はこの`tu`をマーカーとして使う。

#### 数字テーブル(1桁の値、0〜15)

子音`p/k/m/s`×母音`a/e/i/o`の1音節で0〜15の値を表す。値 = 行(子音)×4+列(母音)。

| 値  | 語  |     | 値  | 語  |
| --- | --- | --- | --- | --- |
| 0   | pa  |     | 8   | ma  |
| 1   | pe  |     | 9   | me  |
| 2   | pi  |     | 10  | mi  |
| 3   | po  |     | 11  | mo  |
| 4   | ka  |     | 12  | sa  |
| 5   | ke  |     | 13  | se  |
| 6   | ki  |     | 14  | si  |
| 7   | ko  |     | 15  | so  |

#### 桁位置テーブル(何乗の位か、指数0〜15)

「千」「百」「十」のような語を桁の数だけ個別に用意するのではなく、数字テーブルと同じ規則で「これは10^n(16進数なら16^n)の位か」を1音節で表す専用テーブルを使う。これにより新しい語彙を覚えることなく指数0〜15(10進で10^15の位)まで機械的にカバーできる。

子音`d/g/z/n`(数字テーブルの`p/k/m/s`ともマーカーの`t`とも別)×母音`a/e/i/o`で指数0〜15を表す。値の求め方は数字テーブルと同じ(行×4+列)。

| 指数 | 語  |     | 指数 | 語  |
| ---- | --- | --- | ---- | --- |
| 0    | da  |     | 8    | za  |
| 1    | de  |     | 9    | ze  |
| 2    | di  |     | 10   | zi  |
| 3    | do  |     | 11   | zo  |
| 4    | ga  |     | 12   | na  |
| 5    | ge  |     | 13   | ne  |
| 6    | gi  |     | 14   | ni  |
| 7    | go  |     | 15   | no  |

#### 語の組み立て方

`tu`(マーカー) + 「(数字+桁位置)」の繰り返し + 最後に1の位の数字(省略可)。

- 0でない桁は「数字の音節」の直後に「桁位置の音節」を続けて言う(例: 千の位が2なら`pi`(2)+`do`(指数3) → `pido`)。
- 値が0の桁は言わない(日本語で「1004」を「一千四」と言い、百の位・十の位の「零」を省略するのと同じ)。
- 1の位(指数0)だけは桁位置を付けずに数字だけを言う。1の位が0で他に0でない桁がある場合は1の位ごと省略する。
- 数値全体が0の場合のみ、1の位として`pa`(0)を単独で言う。
- 桁は上位から下位の順に言う(桁位置が明示されるため理論上は順不同でも一意に読めるが、正準形として上位→下位に固定する)。

この方式では、桁位置を聞いた瞬間にその数字がどの位かが分かるため、位取り記数法(桁を並べるだけ)と違い語の途中まで聞いてもそれまでの桁を確定して理解できる。トレードオフとして、0でない桁1つにつき2音節を要する。

例: 1234 → `tu` + `pe`+`do`(千の位=1) + `pi`+`di`(百の位=2) + `po`+`de`(十の位=3) + `ka`(一の位=4) = `tupedopidipodeka`
例: 1000 → `tu` + `pe`+`do`(千の位=1、他の位は0なので省略) = `tupedo`

#### 10進・16進の両立

10進か16進かは`ru`(16進フラグ)の有無だけで決まる。桁の値からの自動判定はしない。

- `ru`が無ければ10進数として読む(桁位置の指数も10のべき乗として解釈)。この場合、桁の値は必ず0〜9でなければならない(10〜15、すなわち数字テーブルの`mi, mo, sa, se, si, so`は使えない)。
- `tu`の直後に`ru`を置くと16進数として読む(桁位置の指数は16のべき乗として解釈)。この場合、桁の値は0〜15まで使える。16進数を言う語には常に`ru`が付く。`ru`は数字テーブル・桁位置テーブルのどの子音とも母音`u`とも被らないため衝突しない。

例: 0x1A2(=418) → `tu`+`ru`+`pe`+`di`(16^2の位=1)+`mi`+`de`(16^1の位=10)+`pi`(1の位=2) = `turupedimidepi`

#### アラビア数字表記(代替入力)

数詞にはアラビア数字による代替入力表記を認める(常に10進数として解釈する)。

- 算用数字をそのまま並べる(例: `12345`)。
- 読みやすさのため、下位から3桁ごとにアンダースコアで区切ってもよい(例: `1_000`、`1_000_000`、`12_345`)。区切りが3桁ごとになっていない場合(`1_00`など)は不正な表記として扱う。

この表記はあくまで入力の代替手段であり、正準形(`get_string`が返す語)は常に`tu`から始まる数詞の語になる。

### 格

述語の項の直前に置き、意味役割を示す。`sa`(主格)・`si`(対格)は二項述語の項構造(x1, x2)に対応する必須格で、それ以外は付加詞(省略可・複数回の付与は不可)。

- `sa` (主格) — 述語のx1(第一項)
- `si` (対格) — 述語のx2(第二項)

付加詞の格は意味領域ごとにグループ化される。

生物系(だれ)

- `subu` (随伴格) — だれと
- `sube` (奪格・人間起点格) — だれから、だれの
- `subo` (与格・人間目標格) — だれまで、だれに

空間系(どこ)

- `suni` (空間格) — どこで
- `sune` (空間起点格) — どこから
- `suno` (空間目標格) — どこまで

時間系(いつ)

- `sugi` (時間格) — いつ
- `suge` (時間起点格) — いつから

道具系

- `sudu` (具格) — 何々を使って

抽象系

- `sute` (原因格・理由起点格) — 何々のせいで
- `suto` (目的格・理由目標格) — 何々のために

#### 格ごとの項の型

- `sa`/`si`: 述語の`get_argument_types`が返す(x1, x2)の型
- `subu`/`sube`/`subo`: `bV`(生物)
- `sudu`: `dV`(人工物。`da`/`di`/`du`は現状区別していない)
- `sute`/`suto`: `gV|mV|rV|zV`(抽象概念全般。`ka`/`ki`/`ku`の抽象項と同じ範囲)
- `suni`/`sune`/`suno`: 空間を指す指示代名詞(`me`/`be`/`ge`)、または`za`(空間関係。例:「Xの中」「Xの近く」)
- `sugi`/`suge`/`sugo`: 時を指す指示代名詞(`me`/`be`/`ge`)、`ziV`(時間関係)、または`zu`(時間の尺度。例:「6日」「5分間」)

### 接続詞

- `hesute` (結果 -> 原因) - P1した なぜなら P2だから
- `henesute` (結果 -> 反対の原因) - P1したP2なのにもかかわらず
- `hesuto` (原因 -> 結果) - P1なのでP2する
- `henesuto` (反対の原因 -> 結果) - P1なのにもかかわらずP2する
- `hehoma` (and) - P1並びにP2する
- `hehomi` (or) - P1もしくはP2する
- `hehomu` (xor) - P1もしくはP2のどちらか片方だけする
- `hehita` (時間前) - P1の前にP2する
- `hehiti` (同時) - P1、P2を同時にする
- `hehitu` (時間後) - P1の後にP2する
- `hezu` (条件) - P1ならP2する
- `hehema` (例示) - P1例えばP2
- `hehegi` (言い換え) - P1つまりP2
- `hehenu` (対比) - P1、一方P2
- `hehezu` (定義) - P1はP2と同値(P1↔P2)。`hehegi`(単なる言い換え。論理式ではP1∧P2)とは異なり、辞書の定義文を書くための専用の接続詞。`hi`(全称量化マーカー)・`ha`/`hu`(定義用のスキーマ変数)と組み合わせて使う(「項」の節を参照)。

### その他

- `ra`/`ri` (項抽出。それぞれ述語の第一項・第二項を抽出する)
- `he` (命題を項に変換、命題の始まりに置く)
- `ho` (命題を項に変換、命題の終わりに置く)
- `se` (型オーバーライド。格標識(`sa`/`si`/`su[CV]`)の直後・項句の直前に置く任意のトークンで、その項だけを述語の型検査から除外し、任意の型として扱わせる。比喩・見立て表現用。例:「parobe(x1はx2を愛す。x1,x2ともに生物`bV`を要求)sa se ri ditabare si ba」で、本来生物ではない項を主格に置ける)

# 設計意図

エスペラントのように1つの語根から名詞や動詞などを派生させると、語の表層文字列が変化してしまうのでこの方向性は採用せず、ロジバンを参考に述語を用いて表現することにした。
計画言語を学習上で最も労力がかかるのが内容語を覚えることである。
ロジバンではn項述語を覚える労力がかかるが、この計画言語では単項述語、二項述語に制限し、項の取りうる型で分類した。
名詞を表す述語では第一音節ごとに分類規則を設けることで覚えやすく、また初見の語でも意味が類推しやすいように設計した。
語の恣意性の問題から、内容語の指す概念や発音を既存言語を参考にするか、独立に設計するかの選択肢があったが、現状最も国際語として使用されている状況や、言語学の知見やリソースの豊富さから英語を参考に内容語を設計した。
英語から具体的にどう音を借用して述語を作るかの手順は[借用規則](./borrowing.md)にまとめている。

なお`se`は上記の音韻による型推定の仕組みを弱めるものではなく、比喩・見立て表現のために型検査を明示的にバイパスする例外機構として導入したものであり、通常の文では使用しないことを想定している。
