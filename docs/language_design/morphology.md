## 内容語

名詞、形容詞・副詞などの修飾詞は述語から派生させる。

### 述語

二項述語と単項述語に分かれているが、単項述語は統語論において二番目の項にεが入ってる二項述語とみなす。
述語はh・s・t以外の子音から始まり、二音節以上持つ。

#### 名詞を表す述語

f(x1, x2)という二項述語で表現され、x1はx2をxxと定義するという命題を表す。

##### 空間・時間を表す名詞述語(z系)

空間・時間に関わる概念はWordNetでは`abstraction.n.06`(関係・尺度)に存在するが、`suni`/`sune`/`suno`(空間格)・`sugi`/`suge`/`sugo`(時間格)の型検査で他の関係・尺度概念(親族関係、因果関係、重さ・体積の尺度など)と混同しないよう、専用の音節グループとして独立させている。

- `za[CV]+` (空間関係。例:「中」「上」「近く」)
  - abstraction.n.06 -> relation.n.01 -> spatial_relation.n.01
- `zi[CV]+` (時間関係。例:「前」「後」「間」)
  - abstraction.n.06 -> relation.n.01 -> temporal_relation.n.01
- `zu[CV]+` (時間の尺度。例:「日」「分」「年」)
  - abstraction.n.06 -> measure.n.02 -> time_period.n.01
- `ze[CV]+` (空間の尺度。例:「メートル」)
  - abstraction.n.06 -> measure.n.02 -> linear_measure.n.01

`za`(空間関係)・`ze`(空間の尺度)は`Space`型、`zi`(時間関係)・`zu`(時間の尺度)は`Time`型として扱われる。

#### 動詞を表す述語

f(x1)もしくはf(x1, x2)という形式で表され、x1は???をする(自動詞)もしくはx1はx2を対象にとりxxをする(他動詞)という命題を表す。
x1, x2に取れる項は、名詞を表す述語で用いた第一音節の分類に基づく。

- `pa[CV]+` (生物x1が生物x2をxxxする)
  - x1: `bV`, x2: `bV`
- `pe[CV]+` (生物x1が生物以外の物理的実体x2をxxxする)
  - x1: `bV`, x2: `dV|nV`
- `pi[CV]+` (生物x1がxxxする)
  - x1: `bV`
- `po[CV]+` (生物以外の物理的実体x1が生物以外の物理的実体x2をxxxする)
  - x1: `dV|nV`, x2: `dV|nV`
- `pu[CV]+` (生物以外の物理的実体x1がxxxする)
  - x1: `dV|nV`
- `ka[CV]+` (生物x1が抽象概念x2をxxxする)
  - x1: `bV`, x2: `gV|mV|rV|zV`
- `ki[CV]+` (生物以外の物理的実体x1が抽象概念x2をxxxする)
  - x1: `dV|nV`, x2: `gV|mV|rV|zV`
- `ku[CV]+` (抽象概念x1が抽象概念x2をxxxする)
  - x1: `gV|mV|rV|zV`, x2: `gV|mV|rV|zV`

### 項

人称代名詞

- `mi` (私)
- `ma` (私とあなたたち)
- `mu` (あなたを含まない私たち)
- `ba` (あなた)
- `bu` (あなたたち)
- `ga` (誰か、単数か複数か指定しない)
- `gi` (彼/彼女)
- `gu` (彼ら)

指示代名詞

- `me` (これ)
- `be` (それ)
- `ge` (あれ)

指示代名詞は指示物の種類を限定しないため、生物・人工物・その他物理的実体・抽象概念に加えて、空間(`suni`/`sune`/`suno`格の「ここ/そこ/あそこ」)や時間(`sugi`/`suge`/`sugo`格の「いま/そのとき/あのとき」)も指すことができる。

#### 定義用のスキーマ変数

- `za` (x1のスキーマ変数)
- `zi` (x2のスキーマ変数)

`za`/`zi`は指示代名詞と同じく指示物の種類を限定しない。ただし通常の代名詞(定数として、特定の指示対象を表す)とは異なり、`za`/`zi`は述語論理上の**変数**として扱われる。単独では意味を持たず、文頭マーカー`ze`(後述)の直後で量化子(`ta`/`to`)とともに明示的に宣言されて初めて量化される。宣言されずに`za`/`zi`を使うと、束縛されない変数が残るため型検査でエラーになる(「定義専用」であることが規約ではなく検証によって強制される)。`ze`の量化子宣言に`za`/`zi`以外の項(`mi`等)を使うことも、`ta`/`to`以外の量化詞(`te`/`ti`)を使うこともエラーになる。

用途は主に、`dictionary.json`の`definition`(語義を計画言語自身で書くフィールド)で、新語を既知語で言い換える定義文を書くこと。例えば新語`kagurita`を既知語`kaho`(x1はx2に肯定する)で定義する場合:

```
ze ta za ta zi hehezu hesa kagurita sa za si zi hesi kaho sa za si zi
```

これは論理式として`∀za. ∀zi. (kagurita(za,zi) ↔ kaho(za,zi))`になる(`hehezu`は接続詞で、文頭に置いて`hesa`/`hesi`で役割標識した2つの節を取る。詳細は「接続詞」の節を参照)。量化子宣言は`ze`の直後に`(ta|to) 変数`の組を必要なだけ並べる形で、単項述語の定義であれば`ze ta za [本文]`のように`za`だけを宣言すればよい。

## 機能語

### 文の区切り

- `do`

文末に置き、文と文の区切りを示す。文と文の間では必須で、最後の文の後ろでは省略できる(1文だけの場合も省略できる)。

```
A do B do C
A do B do C do
```

### 疑問文マーカー

- `ku`

#### 疑問詞

- `ko` (誰、何、いつ、どこ)

`ko`は代名詞と同じ項の位置に置き、その項を尋ねる。指示物の種類を限定しないため、どの格にも置ける。
`ku`で始まる疑問文の中でのみ使える。

### 全称量化マーカー

- `ze`

文の先頭に置く(`ku`と同じ文法上の位置。開始マーカーのみで閉じマーカーは無い)。直後に量化子(`ta`=∀ または `to`=∃)と変数(`za`/`zi`。定義用のスキーマ変数。「項」の節を参照)の組を必要な数だけ並べてから、平叙文が続く。

```
ze (ta|to) za (ta|to) zi [平叙文]
```

例えば`ze ta za to zi [本文]`なら`∀za. ∃zi. [本文の論理式]`になる。宣言は`za`のみ・`zi`のみ・両方のいずれでもよく、宣言した変数だけが対応する量化子で閉じられる。`za`/`zi`を使わない通常の文には付けない。

`ta`/`to`は元々「量化詞」節で述べたNP量化詞(`ta`=すべての、`to`=少なくとも1つは存在する)だが、全称量化=対象すべてに成り立つ(≈∀)・存在量化=対象の少なくとも1つに成り立つ(≈∃)という対応が個体の量化そのものであるため、`ze`の量化子宣言でも同じ語を`ta`=∀・`to`=∃として再利用する。`te`(多くの)・`ti`(半分の)は古典論理の∀/∃に還元できない一般量化詞であり、`ze`の宣言・後述の様相の量化力のどちらにも使えない(使うと型検査でエラーになる)。

### 様相論理

#### 量化力

「量化詞」節の`ta`/`to`を、可能世界に対する量化として再利用する。必然性=すべての可能世界で成り立つ(≈∀=`ta`)・可能性=ある可能世界で成り立つ(≈∃=`to`)。

- `ta` (必然)
- `to` (可能)

##### モーダルベース

- `hapa` (認識)
  - 量化対象：話し手が知っている事実と矛盾しない世界 w_{epi}
  - hapa ta e (確実にe)
  - hapa to e (eかもしれない)
- `hapi` (義務)
  - 量化対象：法律・規則・道徳を守っている世界 w_{deon}
  - hapi ta e (eしなければならない)
  - hapi to e (eしてもよい)
- `hapu` 能力・状況
  - 量化対象：現実の能力・環境条件を保持した世界 w_{cir}
  - hapu ta e (eを必ずできる)
  - hapu to e (eすることができる)

### 述語の反意化

- `no` — 述語の直前(`ne`と同じ構文位置)に置く単項の派生形態素。論理演算子ではない。

`ne`は命題・事象レベルの否定であり、「Pという事象が存在しない」(`¬∃e.(P(e) ∧ …)`)という矛盾対当(contradictory: PとPでないの二値、隙間が無い)を表す。対して`no`は述語そのものを、元の述語とは独立した新しい原子述語(`no P`は`P`とは無関係な`P`の反意形)に反意化する派生であり、`no P`と`P`の間に論理的な関係(例えば「両方は同時に成り立たない」)は型検査でも意味論(`to_fol`)でも一切保証しない。これにより「良くも悪くもない」のような、`P`にも`no P`にも当てはまらない反対対当(contrary)の隙間を自然に表現できる。

`no`は`ne`と同じ「述語の直前に立つ単項演算子」という構文的な地位を共有するため、`ne no P`/`no ne P`/`no no P`のように直接スタックすることはできない(`ne ne P`が禁止されているのと同じ規則)。`hoba`/`hobi`/`hobu`配下にネストした場合は、両方の述語にそれぞれ反意化がかかる。

`no`は`ne`と同様に文法上の派生パーティクルであり、辞書(`dictionary.json`)に見出し語として登録する対象ではない。既存語の対義語が欲しい場合、新しい借用語を追加するのではなく使用時に`no <既存語>`とその場で合成する。

### 量化詞

- `ta` (すべての)
- `te` (多くの)
- `ti` (半分の)
- `to` (少なくとも1つは存在する)

`ta`(∀に対応)・`to`(∃に対応)は、「全称量化マーカー」節の`ze`宣言、および「様相論理」節の量化力(必然`ta`・可能`to`)としても再利用される。`te`/`ti`はNP量化詞としての用途に限られる。

### 数詞

量化詞`ta`/`te`/`ti`/`to`は母音`a/e/i/o`のみを使い、`tu`だけが未使用のまま残っている。数詞はこの`tu`をマーカーとして使う。`t`で始まる固有名詞(「固有名詞」節参照)も先頭の`ta`〜`to`だけを使い、`tu`は使わないため、数詞とは衝突しない。

#### 数字テーブル(1桁の値、0〜15)

子音`s/k/m/p`×母音`o/a/e/i`の1音節で0〜15の値を表す。値 = 行(子音)×4+列(母音)。

| 値  | 語  |     | 値  | 語  |
| --- | --- | --- | --- | --- |
| 0   | so  |     | 8   | mo  |
| 1   | sa  |     | 9   | ma  |
| 2   | se  |     | 10  | me  |
| 3   | si  |     | 11  | mi  |
| 4   | ko  |     | 12  | po  |
| 5   | ka  |     | 13  | pa  |
| 6   | ke  |     | 14  | pe  |
| 7   | ki  |     | 15  | pi  |

#### 桁位置テーブル(何乗の位か、指数0〜15)

「千」「百」「十」のような語を桁の数だけ個別に用意するのではなく、数字テーブルと同じ規則で「これは10^n(16進数なら16^n)の位か」を1音節で表す専用テーブルを使う。これにより新しい語彙を覚えることなく指数0〜15(10進で10^15の位)まで機械的にカバーできる。

子音`d/g/z/n`(数字テーブルの`s/k/m/p`ともマーカーの`t`とも別)×母音`o/a/e/i`で指数0〜15を表す。値の求め方は数字テーブルと同じ(行×4+列)。

| 指数 | 語  |     | 指数 | 語  |
| ---- | --- | --- | ---- | --- |
| 0    | do  |     | 8    | zo  |
| 1    | da  |     | 9    | za  |
| 2    | de  |     | 10   | ze  |
| 3    | di  |     | 11   | zi  |
| 4    | go  |     | 12   | no  |
| 5    | ga  |     | 13   | na  |
| 6    | ge  |     | 14   | ne  |
| 7    | gi  |     | 15   | ni  |

#### 語の組み立て方

`tu`(マーカー) + 「(数字+桁位置)」の繰り返し + 最後に1の位の数字(省略可)。

- 0でない桁は「数字の音節」の直後に「桁位置の音節」を続けて言う(例: 千の位が2なら`se`(2)+`di`(指数3) → `sedi`)。
- 値が0の桁は言わない(日本語で「1004」を「一千四」と言い、百の位・十の位の「零」を省略するのと同じ)。
- 1の位(指数0)だけは桁位置を付けずに数字だけを言う。1の位が0で他に0でない桁がある場合は1の位ごと省略する。
- 数値全体が0の場合のみ、1の位として`so`(0)を単独で言う。
- 桁は上位から下位の順に言う(桁位置が明示されるため理論上は順不同でも一意に読めるが、正準形として上位→下位に固定する)。

この方式では、桁位置を聞いた瞬間にその数字がどの位かが分かるため、位取り記数法(桁を並べるだけ)と違い語の途中まで聞いてもそれまでの桁を確定して理解できる。トレードオフとして、0でない桁1つにつき2音節を要する。

例: 1234 → `tu` + `sa`+`di`(千の位=1) + `se`+`de`(百の位=2) + `si`+`da`(十の位=3) + `ko`(一の位=4) = `tusadisedesidako`
例: 1000 → `tu` + `sa`+`di`(千の位=1、他の位は0なので省略) = `tusadi`

#### 10進・16進の両立

10進か16進かは`ru`(16進フラグ)の有無だけで決まる。桁の値からの自動判定はしない。

- `ru`が無ければ10進数として読む(桁位置の指数も10のべき乗として解釈)。この場合、桁の値は必ず0〜9でなければならない(10〜15、すなわち数字テーブルの`me, mi, po, pa, pe, pi`は使えない)。
- `tu`の直後に`ru`を置くと16進数として読む(桁位置の指数は16のべき乗として解釈)。この場合、桁の値は0〜15まで使える。16進数を言う語には常に`ru`が付く。`ru`は数字テーブル・桁位置テーブルのどの子音とも母音`u`とも被らないため衝突しない。

例: 0x1A2(=418) → `tu`+`ru`+`sa`+`de`(16^2の位=1)+`me`+`da`(16^1の位=10)+`se`(1の位=2) = `turusademedase`

#### アラビア数字表記(代替入力)

数詞にはアラビア数字による代替入力表記を認める(常に10進数として解釈する)。

- 算用数字をそのまま並べる(例: `12345`)。
- 読みやすさのため、下位から4桁ごとにアンダースコアで区切ってもよい(例: `1_0000`、`1_0000_0000`、`1_2345`)。区切りが4桁ごとになっていない場合(`1_000`など)は不正な表記として扱う。

この表記はあくまで入力の代替手段であり、正準形(`get_string`が返す語)は常に`tu`から始まる数詞の語になる。

### 修飾句の区切り

- `di` (述語修飾句の前置詞)
- `du` (項修飾句の前置詞。項抽出句の後ろに置き、日本語の「〜の」のように関係の基準となる項を添える)

`du`は関係の種類を指定しない。`ri paparatanera du mi`(私のパートナー)も`ri zahona du ri duharora`(床の上)も、抽出された項xと添えた項yの間に何らかの関係があること(論理式では`Of(x, y)`)だけを表し、yを述語のx1やx2に割り当てるわけではない。

### 格

述語の項の直前に置き、意味役割を示す。`sa`(主格)・`si`(対格)は二項述語の項構造(x1, x2)に対応する必須格で、それ以外は付加詞(省略可・複数回の付与は不可)。

- `sa` (主格) — 述語のx1(第一項)
- `si` (対格) — 述語のx2(第二項)

付加詞の格は意味領域ごとにグループ化される。

生物系(だれ)

- `subu` (随伴格) — だれと
- `sube` (奪格・人間起点格) — だれから、だれの
- `subo` (与格・人間目標格) — だれまで、だれに

空間系(どこ)

- `suni` (空間格) — どこで
- `sune` (空間起点格) — どこから
- `suno` (空間目標格) — どこまで

時間系(いつ)

- `sugi` (時間格) — いつ
- `suge` (時間起点格) — いつから
- `sugo` (時間目標格) — いつまで

道具系

- `sudu` (具格) — 何々を使って

抽象系

- `sute` (原因格・理由起点格) — 何々のせいで
- `suto` (目的格・理由目標格) — 何々のために

#### 格ごとの項の型

- `sa`/`si`: 述語の`get_argument_types`が返す(x1, x2)の型
- `subu`/`sube`/`subo`: `bV`(生物)。固有名詞では`heba`/`hebi`と`ta…`(「固有名詞」節参照)も直接満たす。
- `sudu`: `dV|nV`(人工物・その他物理的実体。`da`/`di`/`du`は現状区別していない)。固有名詞では`heda`/`hedi`/`hedu`と`te…`も直接満たす。
- `sute`/`suto`: `gV|mV|rV`(抽象概念。`ka`/`ki`/`ku`の抽象項と異なり、空間・時間の`zV`は含まない)。固有名詞では`hemu`と`to…`も直接満たす。
- `suni`/`sune`/`suno`: 空間を指す指示代名詞(`me`/`be`/`ge`)、または`za`(空間関係。例:「Xの中」「Xの近く」)。固有名詞では`heza`と`ti…`(「固有名詞」節参照)も直接満たす。
- `sugi`/`suge`/`sugo`: 時を指す指示代名詞(`me`/`be`/`ge`)、`ziV`(時間関係)、または`zu`(時間の尺度。例:「6日」「5分間」)。固有名詞では`hezi`も直接満たす。

`ru`(付加詞の項抽出。「その他」節参照)で抽出した項は、抽出に使った格の上記の型を持つ。例えば`ru suni peheta`(食べる場所)は空間の型を持つので、`suni`などの空間格に置ける。

### 接続詞

接続詞は2つの節(命題)を関係づける語で、文頭に置く。

```
接続詞 hesa [節1] hesi [節2]
接続詞 hesi [節1] hesa [節2]
```

- `hesuteto` (原因⇔結果) - `hesa`側が原因、`hesi`側が結果
- `henosuteto` (結果⇔反対の原因) - 逆接的な原因を表す(Pなのにもかかわらず(反対の原因により)Q)
- `hehoma` (and) - `hesa`側と`hesi`側が両方成り立つ
- `hehomi` (or) - `hesa`側と`hesi`側のどちらかが成り立つ
- `hehomu` (xor) - `hesa`側と`hesi`側のどちらか片方だけが成り立つ
- `hehitatu` (時間の前後) - `hesa`側が前、`hesi`側が後の時間関係
- `hehiti` (同時) - `hesa`側と`hesi`側が同時に成り立つ
- `hehito` (直説法条件) - `hesa`側が成り立つなら`hesi`側も成り立つ(P→Q)
- `henohito` (反実仮想条件) - もし`hesa`側が成り立っていたなら`hesi`側も成り立つ
- `hehenu` (対比) - `hesa`側は成り立たないが、`hesi`側は成り立つ
- `hehezu` (定義) - `hesa`側と`hesi`側は同値(P↔Q)。単なる連言(論理式ではP∧Q)とは異なり、辞書の定義文を書くための専用の接続詞。`ze`(全称量化マーカー)・`za`/`zi`(定義用のスキーマ変数)と組み合わせて使う(「項」の節を参照)。


### その他

- `ra`/`ri` (項抽出。それぞれ述語の第一項・第二項を抽出する)
- `re` (事象の項抽出。述語が表す事象そのものを抽出する。「〜すること」)
- `ru` (付加詞の項抽出。`ru <格標識> <述語>`の形で、述語が表す事象のその格の項を抽出する。)

項は常に「抽出詞 + 述語的なもの」で作る。述語的なものとは、述語句か、`he … ho`で囲んだ節のどちらか。

- `he` (節の開始マーカー。節の始まりに置く)
- `ho` (節の終了マーカー。節の終わりに置く)

`he … ho`は節を述語の位置に置くための括弧で、単独では項にならない。`ra`/`ri`/`ru <格標識>`の後ろに置いた節では、節の中で省略した格(`ra`なら`sa`、`ri`なら`si`、`ru K`なら`K`)が空所となり、その項が抽出される。`re`の後ろに置いた節には空所が無く、節が表す事象そのものが抽出される。節の中ではテンス・アスペクト・モダリティや`homa`/`homi`/`homu`も使える。

| 抽出詞    | 述語                          | 節                                                                        |
| --------- | ----------------------------- | ------------------------------------------------------------------------- |
| `ri`      | `ri peheta` (食べる物)        | `ri he peheta sa mi ho` (私が食べる物)                                    |
| `ru suni` | `ru suni peheta` (食べる場所) | `ru suni he hita peheta sa mi si ri nohapare ho` (私がりんごを食べた場所) |
| `re`      | `re peheta` (食べること)      | `re he hita peheta sa mi si ri nohapare ho` (私がりんごを食べたこと)      |

`re`で抽出した項は抽象概念(`gV|mV|rV`)の型を持つので、`sute`/`suto`(原因格・目的格)にも置ける。他の抽出と同じく限定詞・数量詞も付けられる(`mo re he … ho`: このこと)。
- `se` (型の上書き。格標識(`sa`/`si`/`su[CV]`)の直後・項句の直前に置く任意のトークンで、その項だけを述語の型検査から除外し、任意の型として扱わせる。比喩・見立て表現用。例:「parobe(x1はx2を愛す。x1,x2ともに生物`bV`を要求)sa se ri databare si ba」で、本来生物ではない項を主格に置ける)

### 固有名詞

人名・地名・団体名のような固有名詞は、既存語の言い換え(「定義用のスキーマ変数」節参照)では表現できず、かつ本人・当事者がその響きや綴りに愛着を持つものが多い。借用規則([借用規則](./borrowing.md))のような音韻変形を強制すると、この愛着ある響き・綴りが失われてしまう。そこで固有名詞専用の構文として、`he[CV]`の形の開始マーカーと、共通の終了マーカー`hoho`で挟む区間を用意する。

```
he<X> <原語の綴り・発音そのまま> hoho
```

`<X>`には「名詞を表す述語」節の先頭音節のうち、固有名詞で実際に使いそうな8種類を割り当てる。

| 開始マーカー | 対応する名詞述語クラス | 用途                           |
| ------------ | ---------------------- | ------------------------------ |
| `heba`       | `ba` (人)              | 人名                           |
| `hebi`       | `bi` (動物)            | 動物名                         |
| `heza`       | `za` (空間関係)        | 地名など空間的固有名詞         |
| `hezi`       | `zi` (時間関係)        | 記念日・元号など時間的固有名詞 |
| `hemu`       | `mu` (非生物の集団)    | 団体・組織・企業名             |
| `heda`       | `da` (道具)            | 乗り物・装置などの固有名       |
| `hedi`       | `di` (構造物)          | 建造物・ランドマークの固有名   |
| `hedu`       | `du` (その他人工物)    | 製品名・作品名・ブランド名     |

開始マーカーの直後から終了マーカー`hoho`の直前までの区間は、この言語の音韻規則([音韻論](./phonology.md))に一切従わない生の文字列として扱う。空白や任意の文字・表記体系を含めてよく、発音上はこの区間だけ元の言語への符号切り替え(code-switching)として、その言語の発音のまま読む。これにより、本人が愛着を持つ響き・綴りをそのまま保持できる。

`he<X> ... hoho`全体は1つの項(Argument)として振る舞い、`mi`/`za`などの代名詞と同じ統語的な位置(項句)を占める。型検査上は、開始マーカー`<X>`が対応する名詞述語クラスと同じ型を持つ項として扱われる。`heba`/`hebi`は生物、`heda`/`hedi`/`hedu`は人工物、`hemu`は抽象概念という扱いになり、地名を表す`heza`は空間、時間を表す`hezi`は時間の型を持つため、「格ごとの項の型」節の`suni`/`sune`/`suno`(空間格)・`sugi`/`suge`/`sugo`(時間格)をそれぞれ直接満たす(「Xの中」「Xの近く」のような`za`系関係名詞を経由する必要はない)。

終了マーカー`hoho`は開始マーカーの種類によらず共通のため、生の文字列の内部に(前後を空白で区切られた)`hoho`という語を含めることはできない。また`he[CV] ... hoho`はネストできない。

#### t で始まる固有名詞

`he<X> ... hoho`は元の響き・綴りを正確に残せる代わりに長い。
そこで、この言語の音韻に合わせた1語の固有名詞として、 `t` で始まる語も使えるようにする。

```
t<V>[CV]+
```

t の直後の母音で型を表す。a→e→i→oの順に、具体的なものから抽象的なものへ並べている。

| 先頭音節 | 型  | 用途 |
| -------- | --- | ---- ||
| `ta`     | 生物       | 人名・動物名                 |
| `te`     | 物理的実体 | 建造物・乗り物・製品の固有名 |
| `ti`     | 空間       | 地名                         |
| `to`     | 抽象概念   | 団体・組織・企業名           |

- 先頭音節より後ろは、この言語の音韻規則(CV音節の繰り返し)を満たしていればよく、中身は名前の持ち主が自由に決める。借用規則のような変換規則は設けず、辞書にも登録しない。
- 型検査上は、`he<X> ... hoho`と同じく、先頭音節の型を持つ項として扱う。意味論上は、その語自体を名前とする定数になる。
- 同じ名前でも、場所を指すか団体を指すかで形が分かれる(土地としてのカナダは`tikanada`、国家としてのカナダは`tokanada`)。

# 設計意図

エスペラントのように1つの語根から名詞や動詞などを派生させると、語の表層文字列が変化してしまうのでこの方向性は採用せず、ロジバンを参考に述語を用いて表現することにした。
計画言語を学習上で最も労力がかかるのが内容語を覚えることである。
ロジバンではn項述語を覚える労力がかかるが、この計画言語では単項述語、二項述語に制限し、項の取りうる型で分類した。
名詞を表す述語では第一音節ごとに分類規則を設けることで覚えやすく、また初見の語でも意味が類推しやすいように設計した。
語の恣意性の問題から、内容語の指す概念や発音を既存言語を参考にするか、独立に設計するかの選択肢があったが、現状最も国際語として使用されている状況や、言語学の知見やリソースの豊富さから英語を参考に内容語を設計した。
英語から具体的にどう語を借用して述語を作るかの手順は[借用規則](./borrowing.md)にまとめている。

なお`se`は上記の音韻による型推定の仕組みを弱めるものではなく、比喩・見立て表現のために型検査を明示的にバイパスする例外機構として導入したものであり、通常の文では使用しないことを想定している。
