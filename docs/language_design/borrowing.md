# 借用の対象と方針

述語（内容語）の語彙を増やす際に、英語から語を借りて新しい述語を作るための規則を定める。
借用の対象は述語のみであり、項(代名詞)・機能語は閉じたクラスなので対象外とする。

新しい概念が必要になった場合、まず既存の述語の組み合わせ(修飾句`da`/`di`/`du`、命題を項に変換する`he`/`ho`など)で表現できないか検討する。
組み合わせでは表現できない、分解不能な基礎概念(具体物や基本動作など)に限り、英語からの借用を行う。
これは、計画言語の学習負荷が内容語の暗記量に比例するため(`morphology.md`の設計意図を参照)、述語の総数をむやみに増やさないための方針である。

# 手順

1. **概念の分解可能性の検討**
   既存の述語の組み合わせで表現できないか確認する。表現できるなら借用しない。
2. **文法的な形(先頭音節)の決定**
   綴りとは無関係に、意味だけで先頭音節を決める。
   - 実体・モノの概念 → `morphology.md`の名詞を表す述語の表(`ba`/`be`/`bi`/`bu`/`da`/`di`/`du`/`na`/`ne`/`ni`/`no`/`nu`/`ga`/`ge`/`gi`/`gu`/`ma`/`mi`/`mu`/`ra`/`re`/`ri`/`ro`/`ru`/`za`/`zi`/`zu`/`ze`)から、該当するWordNet上位語のクラスを選ぶ。
   - 動作・出来事の概念 → `morphology.md`の動詞を表す述語の表(`pa`/`pe`/`pi`/`po`/`pu`/`ka`/`ki`/`ku`)から、x1・x2の生物性/具象性の組み合わせで選ぶ。
3. **綴りの置き換え**
   英語の**綴り**(英小文字のみ)を、下記の綴りの対応表で採用音素(12子音5母音)に写像する。
4. **CV音節への再構成**
   下記の再音節化規則で、子音クラスタ・語末子音・語頭の母音を解消する。
5. **先頭音節の結合**
   手順2で決めた先頭音節と、手順4で得た語根を連結する。
6. **辞書との衝突チェック**
   生成した形が既存語と同一、または紛らわしい場合は、原因となった挿入母音を`a`→`e`→`i`→`o`→`u`の順に1つずつ試し、衝突しない最初の結果を採用する。
7. **語源の記録**
   `dictionary.json`の当該エントリに、借用元の英単語の綴りを残す(後述のフォーマットを参照)。

# 綴りの対応表

英語の綴りを、採用音素(子音`p`/`b`/`t`/`d`/`k`/`g`/`m`/`n`/`r`/`s`/`z`/`h`、母音`a`/`i`/`u`/`e`/`o`)に写像する。
以下を上から順に適用し、同じ位置で複数の規則に当てはまるときは長く一致するものを優先する。

1. **語頭の黙字**: `kn`→`n`、`wr`→`r`、`gn`→`n`、`ps`→`s`
2. **-tion・-sion など**: 語頭以外の`ti`・`si`の直後に`o`か`a`が続くなら、`s`にする(`i`は落とす)
3. **2〜3文字で1音を表す綴り**

   | 綴り | 対応 |
   | ---- | ---- |
   | sch  | sk   |
   | tch  | t    |
   | ch   | t    |
   | sh   | s    |
   | th   | s    |
   | ph   | h    |
   | ck   | k    |
   | wh   | h    |
   | qu   | kh   |

4. **gh**: 語頭なら`g`、それ以外は発音しない(落とす)
5. **1文字**

   | 綴り                               | 対応                                         |
   | ---------------------------------- | -------------------------------------------- |
   | b, d, g, h, k, m, n, p, r, s, t, z | そのまま                                     |
   | c                                  | `e`/`i`/`y`の前なら`s`、それ以外は`k`        |
   | f                                  | h                                            |
   | v                                  | b                                            |
   | l                                  | r                                            |
   | j                                  | d                                            |
   | x                                  | ks                                           |
   | q                                  | k                                            |
   | w                                  | 母音字の後なら落とす、それ以外は`h`          |
   | y                                  | 語頭で母音字の前なら`h`、それ以外は母音`i`   |
   | a, e, i, o, u                      | そのまま(語末の`e`も母音として残す)          |

6. **重なった子音**: 置き換えた後に同じ子音が並んだら、1つにまとめる(`pp`→`p`)
7. **母音の連続**: 置き換えた後に母音が続いたら、最初の1つだけ残す(`ea`→`e`、`oo`→`o`、`ai`→`a`。`y`・`w`から来たものも含む)

# 再音節化規則

綴りの置き換え後の列を、以下の規則で厳密なCV音節の並びに変形する。

1. 子音が2つ以上連続する場合、最初の子音の直後に母音`a`を挿入して2つのCV音節に分割する。
2. 直前に子音のない母音(語頭の母音)には、子音`h`を補って音節頭とする。
3. 語末が子音で終わる場合、その直後に母音`a`を追加して音節を閉じる(コーダを許さないため)。

# 衝突時のフォールバック

手順6の詳細な手続きを以下に示す。

再音節化(特に規則1・3の挿入母音)の結果、生成した語が辞書内の既存語と全く同じ、または意味の異なる既存語と紛らわしい場合がありうる。
実際に、"hold"(会議を開く。`kahorada`)と"word"(`rihorada`)は、どちらも再音節化で語根が`horada`になり、偶然に同じ語根を持ってしまっている。

このような衝突を避けるため、衝突の原因になった挿入母音(規則1・3で入れた`a`)を、`a`→`e`→`i`→`o`→`u`の順に1つずつ差し替えて試し、既存語と衝突しなくなった最初の結果を正式な形として採用する。
この順序は固定なので、同じ入力からは常に同じ結果が再現できる。

# 語源記録のフォーマット

`dictionary.json`の当該エントリの`original_spelling`に、借用元の英単語の綴りを記録する。語源の無い語では`null`にする。

```json
"kahoraka": {
    "original_spelling": "work",
    "terminal_type": "BinaryPredicate",
    "definition": null,
    "description": "x1(人)はx2(概念)という仕事をする。"
}
```

# 用例

手順1〜5の一連の流れを、具体例で確認する。

## 動詞述語の例: "run"

- 英語 "run"。生物x1のみが行う自動詞([誰かが]走る)なので、動詞述語表の`pi[CV]+`(生物x1のみ)を選ぶ。
- 綴りの置き換え: r→r, u→u, n→n。
- 再音節化: `run`は語末が子音`n`なので、規則3により母音`a`を追加 → `runa`。
- 先頭音節と結合: `pi` + `runa` = `piruna`。

## 名詞述語の例: "coffee"

- 英語 "coffee"。物質(substance)の概念なので、名詞述語表の`ni[CV]+`(substance)を選ぶ。
- 綴りの置き換え: c→k, o→o, ff→h(重なった子音を1つにまとめる), ee→e(母音の連続は最初の1つだけ残す)。
- 再音節化: `kohe`はクラスタも語末子音もないため、そのまま。
- 先頭音節と結合: `ni` + `kohe` = `nikohe`。

# 設計意図

先頭音節を綴りではなく意味(WordNet上位語や項の型)で決めるのは、`morphology.md`で定めた第一音節による型推定の仕組みを、借用語であっても壊さないためである。
借用語だからといって英語の最初の音をそのまま先頭子音に使ってしまうと、初見の語からの意味の類推という設計目標が損なわれる。

綴りの置き換え・再音節化のアルゴリズムを厳密に決定的にしているのは、`readme.md`の設計方針「非決定的より決定的に」に基づく。同じ英単語を誰が変換しても同じ結果になることを優先した。

変換元を英語の発音ではなく綴りにしているのは、次の理由による。

- この言語の主な学習者は英語を母語としない人であり、その多くは英語を文字から学んでいる。綴りから語を予測できる方が、学習者が語を覚えやすく、思い出しやすい。
- 綴りは英米などの地域差が無く、発音辞書を参照しなくても誰でも同じ結果を得られる。発音を基準にすると、どの地域の発音を採るかで結果が変わってしまう。
- 英語の発音を正確に知っている人(英語母語話者など)だけが有利になることを避けられる。

一方で、語中の黙字(`island`の`s`、`climb`の`b`など)も音節になるため、発音ベースより語が長くなることがある。どの文字が発音されないかは綴りだけでは決まらないため、これは決定性を保つための代償として受け入れる。
