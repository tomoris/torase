# 借用の対象と方針

述語（内容語）の語彙を増やす際に、英語から音を借りて新しい述語を作るための規則を定める。
借用の対象は述語のみであり、項(代名詞)・機能語は閉じたクラスなので対象外とする。

新しい概念が必要になった場合、まず既存の述語の組み合わせ(修飾句`da`/`di`/`du`、命題を項に変換する`he`/`ho`など)で表現できないか検討する。
組み合わせでは表現できない、分解不能な基礎概念(具体物や基本動作など)に限り、英語からの音借用を行う。
これは、計画言語の学習負荷が内容語の暗記量に比例するため(`morphology.md`の設計意図を参照)、述語の総数をむやみに増やさないための方針である。

# 手順

1. **概念の分解可能性の検討**
   既存の述語の組み合わせで表現できないか確認する。表現できるなら借用しない。
2. **文法的な形(先頭音節)の決定**
   発音とは無関係に、意味だけで先頭音節を決める。
   - 実体・モノの概念 → `morphology.md`の名詞を表す述語の表(`ba`/`be`/`bi`/`bu`/`da`/`di`/`du`/`na`/`ne`/`ni`/`no`/`nu`/`ga`/`ge`/`gi`/`gu`/`ma`/`mi`/`mu`/`ra`/`re`/`ri`/`ro`/`ru`/`za`/`zi`/`zu`/`ze`)から、該当するWordNet上位語のクラスを選ぶ。
   - 動作・出来事の概念 → `morphology.md`の動詞を表す述語の表(`pa`/`pe`/`pi`/`po`/`pu`/`ka`/`ki`/`ku`)から、x1・x2の生物性/具象性の組み合わせで選ぶ。
3. **発音ベースの音素変換**
   英語の**発音**(綴りではない)を、下記の音素対応表で採用音素(12子音5母音)に写像する。
4. **CV音節への再構成**
   下記の再音節化規則で、子音クラスタ・語末子音・母音連続を解消する。
5. **先頭音節の結合**
   手順2で決めた先頭音節と、手順4で得た語根を連結する。
6. **辞書との衝突チェック**
   生成した形が既存語と同一、または紛らわしい場合は、原因となった挿入母音を`a`→`e`→`i`→`o`→`u`の順に1つずつ試し、衝突しない最初の結果を採用する。
7. **語源の記録**
   `dictionary.json`の当該エントリに、借用元の英単語の綴り・発音を残す(後述のフォーマットを参照)。

# 音素対応表

英語の発音記号(IPA)を、採用音素(子音`p`/`b`/`t`/`d`/`k`/`g`/`m`/`n`/`r`/`s`/`z`/`h`、母音`a`/`i`/`u`/`e`/`o`)に写像する。

## 子音

| 英語音                             | 対応     | 備考                                                             |
| ---------------------------------- | -------- | ---------------------------------------------------------------- |
| p, b, t, d, k, g, m, n, r, s, z, h | そのまま | 採用済みの12子音に含まれる                                       |
| f                                  | h        | 唇歯摩擦音 → 声門摩擦音                                          |
| v                                  | b        | 有声唇歯摩擦音 → 有声唇音破裂音                                  |
| θ (thin)                           | s        | 無声歯摩擦音 → 無声歯茎摩擦音                                    |
| ð (this)                           | d        | 有声歯摩擦音 → 有声歯茎破裂音(θ→sと有声対応を揃える)             |
| ʃ (sh)                             | s        | 無声後部歯茎摩擦音 → 無声歯茎摩擦音                              |
| ʒ (measure)                        | z        | 有声後部歯茎摩擦音 → 有声歯茎摩擦音                              |
| tʃ (ch)                            | t        | 破擦音の摩擦要素を落とし無声破裂音にする                         |
| dʒ (judge)                         | d        | 破擦音の摩擦要素を落とし有声破裂音にする(tʃ→tと有声対応を揃える) |
| l                                  | r        | 流音は`r`に統合する                                              |
| w, j                               | h        | 半母音(接近音)は対応する子音を持たないため`h`に統合する          |
| ŋ (sing)                           | n        | 軟口蓋鼻音 → 歯茎鼻音                                            |

## 母音

| 英語音                                     | 対応       | 備考                                                                       |
| ------------------------------------------ | ---------- | -------------------------------------------------------------------------- |
| iː, ɪ                                      | i          |                                                                            |
| eɪ, e, ɛ                                   | e          | 二重母音eɪも単母音へ                                                       |
| æ, ʌ, ə(シュワ)                            | a          |                                                                            |
| ɑː, ɒ, ɔː, oʊ                              | o          |                                                                            |
| uː, ʊ                                      | u          |                                                                            |
| aɪ, aʊ                                     | a          | 開始の母音の音色を採用する(CVはVVを許さないため二重母音は必ず単母音化する) |
| ɔɪ                                         | o          | 同上                                                                       |
| rを伴う母音(ɜːr, ər, ɑːr, ɔːr, ɪr, ʊrなど) | 母音+子音r | 母音部分を上記の対応で写像し、続けて子音`r`を置く                          |

# 再音節化規則

音素変換後の列を、以下の規則で厳密なCV音節の並びに変形する。

1. 子音が2つ以上連続する場合、最初の子音の直後に母音`a`を挿入して2つのCV音節に分割する。
2. 直前に子音のない母音(語頭の母音、または`w`/`j`が`h`に統合された結果生じる母音)には、子音`h`を補って音節頭とする。
3. 語末が子音で終わる場合、その直後に母音`a`を追加して音節を閉じる(コーダを許さないため)。

# 衝突時のフォールバック

手順6の詳細な手続きを以下に示す。

再音節化(特に規則1・3の挿入母音)の結果、生成した語が辞書内の既存語と全く同じ、または意味の異なる既存語と紛らわしい場合がありうる。
実際に、"hold"(会議を開く。`kahorada`)と"word"(`rihorada`)は、どちらも再音節化で語根が`horada`になり、偶然に同音の語根を持ってしまっている。

このような衝突を避けるため、衝突の原因になった挿入母音(規則1・3で入れた`a`)を、`a`→`e`→`i`→`o`→`u`の順に1つずつ差し替えて試し、既存語と衝突しなくなった最初の結果を正式な形として採用する。
この順序は固定なので、同じ入力からは常に同じ結果が再現できる。

# 語源記録のフォーマット

`dictionary.json`の当該エントリに、`original_spelling`(借用元の英単語の綴り)と`original_pronunciation`(発音のIPA表記)を記録する。この2つは両方記録するか、語源の無い語では両方`null`にする。

```json
"kahoraka": {
    "original_spelling": "work",
    "original_pronunciation": "wɜːrk",
    "terminal_type": "BinaryPredicate",
    "definition": null,
    "description": "x1(人)はx2(概念)という仕事をする。"
}
```

# 用例

手順1〜5の一連の流れを、具体例で確認する。

## 動詞述語の例: "run"

- 英語 "run" /rʌn/。生物x1のみが行う自動詞([誰かが]走る)なので、動詞述語表の`pi[CV]+`(生物x1のみ)を選ぶ。
- 発音 /rʌn/ を音素変換: r→r, ʌ→a, n→n。
- 再音節化: `ran`は語末が子音`n`なので、規則3により母音`a`を追加 → `rana`。
- 先頭音節と結合: `pi` + `rana` = `pirana`。

## 名詞述語の例: "coffee"

- 英語 "coffee" /ˈkɒfi/。物質(substance)の概念なので、名詞述語表の`ni[CV]+`(substance)を選ぶ。
- 発音 /ˈkɒfi/ を音素変換: k→k, ɒ→o, f→h, i→i。
- 再音節化: `kohi`はクラスタも語末子音もないため、そのまま。
- 先頭音節と結合: `ni` + `kohi` = `nikohi`。

# 設計意図

先頭音節を発音ではなく意味(WordNet上位語や項の型)で決めるのは、`morphology.md`で定めた第一音節による型推定の仕組みを、借用語であっても壊さないためである。
借用語だからといって英語の最初の音をそのまま先頭子音に使ってしまうと、初見の語からの意味の類推という設計目標が損なわれる。

音素変換・再音節化のアルゴリズムを厳密に決定的にしているのは、`readme.md`の設計方針「非決定的より決定的に」に基づく。同じ英単語を誰が変換しても同じ結果になることを優先した。

変換元を英語の綴りではなく発音(IPA)にしているのは、この言語の音韻体系がそもそも発音(音素)ベースで設計されており、既存の借用語(`dahone`=phoneなど)もすべて発音を基準に作られているためである。英語の綴りは不規則で(`though`/`through`/`rough`/`cough`の`-ough`が5通りに読まれるなど)、綴りベースにすると結局は発音を経由した個別ルールが必要になり一貫しない。発音辞書を都度参照する手間はかかるが、`night`と`knight`のような綴りの異なる同音語が自然に同じ形になるなど、決定性と一貫性の面で優れるため発音ベースを採用する。

なお、これまでに作られた借用語(`pemarige`=marriageの dʒ→g、`guresona`=reasonの z→s など)は、上記の音素対応表とは一部異なる対応になっているものがある。これらの既存語は書き換えず、今後新しく作る借用語からこの規則を適用する。
