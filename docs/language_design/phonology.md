
# 採用音素

[国際音声記号](https://ja.wikipedia.org/wiki/%E5%9B%BD%E9%9A%9B%E9%9F%B3%E5%A3%B0%E8%A8%98%E5%8F%B7)

発音する際には、微妙な違いで発音しても聞き手が弁別できればよく、厳密な発音を強制しない。
特に母音の半狭や子音のrなど。

## 母音

|      | 前舌 (Front) | 中舌 (Central) | 後舌 (Back) |
| ---- | ------------ | --------- | - |
| 狭   | i            |           | u |
| 半狭  | e            |           | o |
| 広   | a            |          |   |

| -------| -------- | -------- | ----- | ------- |
| 破裂音  | p / b    | t / d    | k / g |         |
| 鼻音    | m        | n        |       |         |
| ふるえ音 |          | r        |       |         |
| 摩擦音  |          | s        |       | h       |

# 音節

子音＋母音(CV)のみを採用する。

# アクセント・声調

アクセント位置は常に語の第1音節に置き、そのアクセントのある母音を少し長めに発音する。
声調は区別しない。

# 設計意図

多くの言語に含まれる音素を採用した。
音節はCCやVVを許すと音変化が起きやすくなるので採用しない。
