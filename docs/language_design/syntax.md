# 特徴

孤立語的要素を強く持ち、語の屈折や接辞は起こらない。
基本語順はVSOを採用し、VOSも許す。
句の構造において、常に主要部が先に出現する。

# 文法

## 文法クラス

LL(1)文法を採用する。

## 文の種類

- 平叙文
  - 疑問文、命令・勧誘・許可文以外のすべて
- 疑問文
  - 文の先頭に疑問文を表すマーカー`ku|?`をつけることで命題を疑問文化する
  - 文中の項の位置に`ko`を置くことでその位置の項の中身を問う補足疑問文を作る
- 命令・勧誘・許可文
  - 命令・勧誘・許可のモダリティを用いて作る

# 設計意図

語は変化しない方が学習しやすいと判断したため、孤立語的な設計にした。
重要な情報は先に伝えるべきと考え、常に主要部が先に出現する語順にした。
学習難易度的にCFGの中でもできるだけ最小限の文法にしたかった。
また、解析時の負荷が低く、トップダウン解析できること、漸進的解析ができることからLL(1)文法を採用した。
平叙文のマーカーはεにするなど、頻出しそうな表現は明示的なマーカーがなかったり省略できたりと文長を短くできる設計にした。
